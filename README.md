# Frontier Hunts

Hunting, wildlife and fieldcraft for **Minecraft 1.21.1**, by **FormaWorks**.

Track wildlife, prepare field equipment, build a hunting camp and explore with friends. Version **1.4.0** adds Field Phone photography, selfies, photo messages and emoji, with snowmobile and rendering improvements.

**[Download 1.4.0](https://github.com/FormaWorkss/frontier-hunts/releases/tag/v1.4.0)** · **[Download 1.3.1](https://github.com/FormaWorkss/frontier-hunts/releases/tag/v1.3.1)** · **[Discord](https://discord.gg/qgF5u973ue)**

## Install

1. Use **Minecraft 1.21.1, NeoForge 21.1.248 and Java 21**.
2. Download the protected ZIP from a release and extract with **7-Zip or WinRAR**, using the password supplied separately.
3. Close Minecraft. Place the extracted `FrontierHunts` JAR in your instance's `mods` folder, replacing the older version.
4. Use the same version on clients and servers. **Frontier Structures 1.2.0 is bundled**; do not install a second copy separately.

Downloads are repeatable and have no scheduled expiry. No installer or antivirus changes are needed. Each release includes SHA-256 checksums for its ZIP and JAR.
