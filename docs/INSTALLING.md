# Installing Frontier Hunts

Use Minecraft 1.21.1, NeoForge 21.1.248 and Java 21. Download the desired release ZIP, extract it using 7-Zip or WinRAR and the separately supplied password, then put the extracted JAR in your instance's mods folder with Minecraft closed. Remove the previous Frontier Hunts JAR first.

Frontier Structures is bundled: do not install a second copy. Clients and servers should use the same Frontier Hunts version. Back up your world before updating.

Compare your ZIP and extracted JAR against that release's SHA256SUMS.txt using PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath 'filename'`.
