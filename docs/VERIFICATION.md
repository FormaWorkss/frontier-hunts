# Download verification

These maintenance packages change author names and internal package identifiers to FormaWorks. Audio recordings are byte-for-byte identical to the original supplied releases. All other non-name content is unchanged, and Java method instructions remain unchanged.

Both JARs passed archive-integrity checks and a full scan for the removed author name. The extracted protected ZIP contents match their packaged JAR hashes. Each release includes SHA256SUMS.txt for its ZIP and JAR.

This is a name-only archive rebuild, not a new gameplay release or a complete gameplay/security audit. No new source compilation or native gameplay test was performed on these exact packages. See the existing known issues and install instructions before updating.
