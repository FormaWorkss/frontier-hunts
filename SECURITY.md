# Security reporting

For suspected security vulnerabilities in the shared 1.4.0 and 1.3.1 release, use [GitHub's private vulnerability report](https://github.com/FormaWorkss/frontier-hunts/security/advisories/new). Do not post exploitation instructions, passwords or other people's data in a public issue.

Include the affected version, expected and observed behavior, reproduction steps in a test environment, and the potential impact. Remove access tokens, passwords, personal paths and private server details from attachments.

Ordinary installation problems, crashes and gameplay bugs belong in [Issues](https://github.com/FormaWorkss/frontier-hunts/issues/new/choose). Reporting is welcome; no response-time guarantee or bug-bounty program is offered.

## Download verification

Use releases from this repository, compare [SHA256SUMS.txt](SHA256SUMS.txt), and scan the extracted JAR with your own security software. The archive password is shared separately by the maintainer. Never post it in a public issue.

Do not disable antivirus or install an unrelated executable to use the mod. A hash match or a clean scanner result does not guarantee the absence of vulnerabilities. The scope of checks performed is recorded in [verification details](docs/VERIFICATION.md).
